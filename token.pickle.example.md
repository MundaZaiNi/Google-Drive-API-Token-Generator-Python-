# token.pickle — Demo Placeholder

This is documentation only, not a real pickle token.

`token.pickle` is a binary file generated locally after successful Google OAuth authentication. It must not be committed to a public repository.

To generate your own token:
1. Download OAuth credentials for a Desktop app from Google Cloud.
2. Save them as `credentials.json` beside `generate_token.py`.
3. Install dependencies with `python -m pip install -r requirements.txt`.
4. Run `python generate_token.py`.

Only load pickle files you created or trust.
